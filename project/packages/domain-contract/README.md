# depa-codument-domain-contract

Codument domain data and explicit operation ports. Lifecycle snapshots retain the
complete XNL authority tree; summaries and verification receipts are projections.
No filesystem, process, clock, workspace defaults, or Host bootstrap lives here.

The initial public slice includes Track/Mission lifecycle, verification, registry
contracts and nine code-owned Kind descriptors. These revisions remain
experimental: structural admission is not full domain semantic validation.
Repository transactions, archive promotion and migration are not yet provided.
A `VerificationReceipt` is data, not a capability to bypass its owner's
workspace/freshness checks.
