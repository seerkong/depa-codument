未初始化：`codument init-workspace`（如需同时初始化全局状态，使用 `codument init`）
已初始化：`codument upgrade-workspace`
查看状态：`codument status`

安装目标固定为 Codex `.agents/skills`，不接受安装侧 `--agent` 或 `--skills-dir`。
